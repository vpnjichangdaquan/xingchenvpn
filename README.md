## 使用建议与线路选择

### 节点选择建议

选择节点时可以按照以下原则：

1. 优先测试距离较近的节点。
2. 比较不同节点的延迟。
3. 对影音服务进行实际播放测试。
4. 对 AI 服务进行实际访问测试。
5. 高峰期如果出现速度下降，可以尝试切换其他节点。
6. 对线路质量要求较高时，可以优先测试套餐中提供的 IEPL 等线路。

### 高峰期优化建议

在晚间等网络使用高峰期，部分节点可能出现负载增加。

可以尝试：

* 更换同地区其他节点
* 更换不同国家或地区节点
* 测试专线节点
* 避免长时间使用高负载节点
* 对比不同时间段的速度表现

### 网络异常处理方法

如果出现连接异常，可以依次检查：

1. 当前设备是否正常联网。
2. 订阅是否已经过期。
3. 客户端是否成功更新订阅。
4. 当前节点是否正常。
5. 更换其他节点测试。
6. 重启客户端后再次连接。
7. 如果仍然无法解决，可以根据套餐提供的客服渠道提交工单。
